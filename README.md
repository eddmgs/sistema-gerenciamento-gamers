# sistema-gerenciamento-gamers
Sistema de gerenciamento de jogadores desenvolvido em JavaScript e Node.js.
🎮 Sistema de Gerenciamento de Gamers

📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática de programação utilizando JavaScript com Node.js.

O sistema permite realizar operações básicas de gerenciamento de jogadores de uma equipe, como:

Cadastrar jogadores;

Listar jogadores cadastrados;

Excluir jogadores;

Atualizar a pontuação dos jogadores;

Calcular a média de pontuação da equipe;

Encerrar o programa.


O projeto foi desenvolvido com o objetivo de aplicar conceitos fundamentais de programação, como variáveis, arrays, objetos, funções, estruturas condicionais, estruturas de repetição e entrada de dados pelo terminal.

🎯 Objetivos

O principal objetivo do projeto é colocar em prática conceitos básicos da linguagem JavaScript por meio da construção de um sistema interativo executado no terminal.

Durante o desenvolvimento foram utilizados conceitos importantes da programação:


Variáveis;

Constantes;

Arrays;

Objetos;

Funções;

Estruturas condicionais;

Estruturas de repetição;

Métodos de arrays;

Conversão de tipos;

Validação de dados;

Entrada e saída de dados;

Organização de código.



💻 Linguagem e tecnologias utilizadas

Neste projeto, o JavaScript é executado através do Node.js, permitindo que o programa funcione diretamente pelo terminal.
